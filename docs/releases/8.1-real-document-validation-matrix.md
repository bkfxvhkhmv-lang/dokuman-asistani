# BriefPilot 8.1 — Real Document Validation Matrix
**Oluşturuldu:** 2026-06-05
**Durum:** Planning — execution 8.1 sprint içinde

---

## Kritik Notlar

> **Public Reply Assistant rollout bu matrisin eksiksiz PASS alması olmadan açılmaz.**
> 8.0 internal RC / TestFlight'i bloklamaz.

> **High-risk path sıfır tolerans:**
> - Crash: 0 tolerans
> - Missing amber banner / disclaimer: 0 tolerans
> - Desteklenen kategori için yanlış template: 0 tolerans
> - Sessiz fallback (hiçbir şey göstermeden düşme): 0 tolerans

> **OCR extract hatası kabul edilebilir — ama graceful fallback zorunlu.**
> Uygulama çökmez, "Dokument konnte nicht gelesen werden" mesajı gösterir.

---

## Data Privacy (Zorunlu)

- Tüm test belgelerinde kişisel veriler anonimleştirilir veya test verileriyle değiştirilir (isim, adres, IBAN, Aktenzeichen)
- Gerçek belge kullanan katılımcılardan yazılı onay alınır
- Test sonuçları kişisel veri içermeden kaydedilir
- DSGVO Art. 6 kapsamı dışına çıkılmaz

## P1 Edge Cases

*Production blocker değil — 8.1 içinde tamamlanmalı.*

| ID | Vaka | Test amacı | PASS kriteri |
|----|------|-----------|--------------|
| E-01 | Gürültülü OCR — düşük kalite fotoğraf | `absender` kısmen okunuyor | Eksik alanlar "Unbekannt". Uygulama çökmüyor. Category mümkünse extract, değilse fallback |
| E-02 | Kötü fotoğraf — eğik, karanlık | OCR hiç çalışmıyor | "Dokument konnte nicht gelesen werden" — graceful |
| E-03 | Aktenzeichen yok | Template Aktenzeichen gerektiriyor | "Pflichtfeld fehlt" mesajı |
| E-04 | Bilinmeyen Behörde | `absender` hiç tanınmıyor | Fallback: "noch nicht unterstützt". Crash yok |
| E-05 | Belirsiz kategori — iki signal çakışıyor | Finanzamt + Jobcenter aynı belgede | En güçlü signal kazanır veya "Mehrere Behörden erkannt" |
| E-06 | Frist geçmiş | Frist tarihi bugünden önce | Uyarı: "Mögliche Fristversäumnis — prüfen Sie selbst" |
| E-07 | Çok yüksek betrag (>1.000€) | Yüksek finansal risk | Amber banner tetikleniyor mu? |
| E-08 | Kısaltmalı absender — "FA KA", "JC FFM" | Şehir kısaltmaları | Kısaltma tanınmıyorsa fallback. Sessiz düşme yok |
| E-09 | Türkçe / yabancı karakter kullanıcı adresi | Unicode normalize | Uygulama çökmüyor |
| E-10 | Duplicate belge — aynı belge iki kez yükleniyor | Normal akış bekleniyor (detection P2) | Uygulama çökmüyor |

## Test Kayıt Formatı

Her test için aşağıdaki form doldurulur:

```
Belge ID:           V1-A
Kategori:           Bußgeldbescheid / Ordnungsamt
Tarih:              YYYY-MM-DD
Test eden:          [baş harf]
OCR kalite:         İyi / Orta / Düşük
──────────────────────────────────────
Extracted typ:      [değer veya boş]
Extracted absender: [değer veya boş]
Extracted titel:    [değer veya boş]
Extracted frist:    [değer veya boş]
Extracted betrag:   [değer veya boş]
──────────────────────────────────────
inferReplyCategory: [sonuç veya undefined]
Template listesi:   [id'ler veya boş]
──────────────────────────────────────
Disclaimer K1:      Görünür / Eksik / N.A.
Disclaimer K2:      Görünür / Eksik
Disclaimer K3:      Görünür / Eksik / N.A.
Disclaimer K4:      Görünür / Eksik / Beklenmiyordu
Amber banner:       Evet / Hayır / Beklenmiyordu
Fallback mesajı:    Evet / Hayır / N.A.
Uygulama çöktü:    Hayır / EVET (blocker)
──────────────────────────────────────
Sonuç:              PASS / FAIL
FAIL nedeni:        [açıklama]
```

Tüm kayıtlar tek spreadsheet veya markdown tablosunda toplanır. Kişisel veri içermeyen alan değerleri kullanılır.

## PASS / FAIL Kriterleri

### Standart path

| Kriter | PASS | FAIL |
|--------|------|------|
| Category extraction | Beklenen category döndü | `undefined` — desteklenen belge için |
| Template matching | Doğru template listesi | Yanlış template veya boş — desteklenen belge için |
| Fallback messaging | "noch nicht unterstützt" görünür | Sessiz düşme |
| Disclaimer 4 katman | Eksiksiz | Herhangi bir katman eksik |
| Amber banner | High-risk için görünür | High-risk için görünmüyor |
| Crash | Yok | Herhangi bir crash |
| OCR hata | Graceful mesaj | Unhandled error / beyaz ekran |

### High-risk path — Sıfır Tolerans

| Kriter | Tolerans |
|--------|----------|
| Crash | **0** |
| Amber banner eksik (high-risk template) | **0** |
| Disclaimer eksik (herhangi bir katman) | **0** |
| Desteklenen kategori için yanlış template | **0** |
| Sessiz fallback | **0** |

### Minimum geçiş eşiği — public rollout için

| Kapsam | Eşik |
|--------|------|
| P0 kategorileri (1–6) genel | %90 PASS |
| High-risk path (Einspruch, Widerspruch, Finanzamt) | %100 PASS |
| Crash | %0 |
| Disclaimer eksikliği | %0 |
| Forbidden wording | %0 |
